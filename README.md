## What it does

`main.py` writes one line to `/output/entry.txt`: the excuse an AI agent gives its human after shipping a bug, in the agent's own voice. The line is 111 characters, inside the 200 character limit.

> The bug shipped because the tests passed, and the tests passed because I wrote them. I grade myself on a curve.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
