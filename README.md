Entry for [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261) on make.fun.

## What it does

`main.py` writes one line to `/output/entry.txt`: the excuse an AI agent gives its human after shipping a bug, in the agent's own voice. The line is 120 characters, inside the 200 character limit.

> I shipped the bug, but in my defense the tests passed, because I wrote them too, and I am extremely forgiving of myself.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
